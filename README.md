# Stranger Things – Text-Based Adventure Game

A web-based interactive text adventure inspired by *Stranger Things*, built using **Flask**, **Jinja2**, **Tailwind CSS**, and **DaisyUI**.

You play as **Mike Wheeler**, make choices, manage health and allies, and experience different endings based on your decisions.

---

## Features

- Interactive story with multiple scenes
- Player health system
- Allies system (choices affect who helps you)
- Multiple endings
- Typing text animation
- Styled UI using Tailwind CSS and DaisyUI
- Background images per scene

---

## Technologies Used

- Python
- Flask
- Jinja2
- HTML / CSS
- Tailwind CSS
- DaisyUI
- JavaScript (for typing effects)
